1 · 说话人参考（1–5 人，零样本克隆）

每位说话人上传 3–10 秒干净人声，并填写该段参考音频的逐字稿（必须与音频内容一致， 脚本里用 [S1]/[S2] 对应）。参考音频决定音色，逐字稿影响韵律对齐。

2 · 对话脚本与参数

脚本按 [S1] … [S2] … 交替书写；模型一次连续生成整段对话（含轮次切换与重叠韵律）。

高级采样参数（TTSD 官方推荐 1.1 / 0.9 / 50 / 1.1）

1 · 参考音色（零样本克隆）

参考音频决定音色，与文本语言无关。内置音色列表直接可用；换成自己的录音时， 上传 3–10 秒干净人声（无混响、无背景音乐）效果最稳。

2 · 待转换文本与参数

高级采样参数（MOSS-TTS Delay-8B 官方推荐 1.7 / 0.8 / 25 / 1.0）

MOSS-TTS 是基座模型，对采样参数敏感：官方推荐值之外的组合容易丢结尾或出现循环。

1 · 音色描述（无需参考音频）

用自由文本描述想要的音色与说话方式：性别、年龄、音质、情绪、语速、口音…… 模型据此"设计"出音色再念出右侧文本。中文、英文质量最好，描述越具体越稳。

2 · 待合成文本与参数

高级采样参数（MOSS-VoiceGenerator 官方推荐 1.5 / 0.6 / 50 / 1.1）

官方模型卡提示：该模型对采样参数敏感，偏离推荐值容易音色漂移或丢结尾。

1 · 音效描述

用自然语言描述环境声/拟音，越具体越好：场景、材质、距离、节奏。

高级采样参数（SoundEffect 官方推荐 1.5 / 0.6 / 50 / 1.2）

使用说明

  • 首次使用：在「模型与输出」页点「加载」即可——四种生成模式默认都用已优化的 int8 + no-head 落盘产物（表格里会显示具体用哪个产物），启动快、显存低，不需要先选量化方式。fp8 / 无量化需要完整精度权重在位，本机母本已于 2026-10-14 删除（腾系统盘）⇒ 这两档不再出现在界面里；哪天把权重重下回来，它们会自动重新出现。
  • 单人配音 / 音色克隆：MOSS-TTS-v1.5（8B delay 模型）做零样本克隆——一段 3–10 秒参考音频 + 待转文本即可，参考音频决定音色，与文本语言无关；支持 31 种语言、中英混说、[pause 1.5s] 停顿与拼音（ni3 hao3）发音控制。内置音色列表在 D:\MossTTSD\assets\voices\（可直接替换成自己的参考音频）。采样参数请用官方推荐值（1.7 / 0.8 / 25 / 1.0）。
  • 音色设计：MOSS-VoiceGenerator（1.7B delay）用自由文本描述音色与说话方式（性别 / 年龄 / 音质 / 情绪 / 语速 / 口音），不需要参考音频——描述与文本一起送入模型，直接产出该音色的配音。想把设计好的音色固定下来：生成后下载 wav，再拿到「单人配音」页当参考音频做克隆。采样参数用官方推荐值（1.5 / 0.6 / 50 / 1.1）。
  • 对话配音：每位说话人需要一段参考音频 + 逐字稿；脚本用 [S1]/[S2] 标注轮次。参考音频质量直接决定音色相似度。
  • 长文本：单次建议 ≤ 3 分钟，过长会显著增加显存占用（KV cache 随上下文增长）。
  • 音效生成：时长通过 token 上限控制，实际输出可能略短（模型自然结束）。
  • 采样参数：温度过低易丢句子结尾，过高易出现循环/杂音；先按官方推荐值，再微调。
  • 验收：生成完成后务必完整试听，确认内容完整、无异常噪声；只看时长/文件大小不足以判定质量。
