# MOSS 语音工作台 · 运行时依赖（单环境安装用）
#
# 用法（Python 3.12 x64）：
#   python -m venv runtime/venv
#   runtime\venv\Scripts\python.exe -m pip install -U pip
#   runtime\venv\Scripts\python.exe -m pip install -r runtime\requirements.txt ^
#       --extra-index-url https://download.pytorch.org/whl/cu130
#
# 说明：
#  - 本文件是**单环境**依赖清单：由现存「venv + runtime/pylibs 覆盖层」两套栈的实际安装版本合并而来，
#    冲突项取覆盖层版本（transformers 5.19 / huggingface_hub 2.2 / safetensors 0.8 / tokenizers 0.23 /
#    tqdm 4.70 / hf-xet 1.7）——装好后不再需要靠 PYTHONPATH 覆盖层来改版本。
#  - torch / torchaudio 带 +cu130 本地版本号，只存在于 https://download.pytorch.org/whl/cu130，
#    因此必须带上面的 --extra-index-url（或整体用 --index-url 指向该源 + PyPI 作为 extra）。
#    已在该源确认存在 torch-2.10.0+cu130-cp312-cp312-win_amd64.whl 与同名 torchaudio 轮子。
#  - 本清单只钉**直接依赖**：pip 会按各包声明的依赖自动补齐间接依赖
#    （例：optimum-quanto→ninja、demucs→julius/lameenc/pyyaml/sphn、faster-whisper→av/onnxruntime/ctranslate2）。
#  - 已逐条核实（2026-10-15）：74 条在 Windows + Python 3.12 下都有现成轮子（无需编译）；
#    以「本清单的 pin」为版本，各包互相声明的版本范围无冲突。
#  - 装机量约 3.4 GB（解包后 ~3.6 GB），主要是 torch 的 CUDA DLL。
#  - **不在本文件内、必须随包提供**：runtime/pylibs/mossformer2_se（vendored 架构代码，PyPI 无对应包）、
#    ffmpeg（runtime/ffmpeg，或目标机 PATH 上有 ffmpeg）、以及基础解释器本身（client/python 或用户自装 Python 3.12）。
#  - **已刻意排除**：torchcodec（无人依赖：torchaudio 只依赖 torch；且本机它的原生库加载失败，代码已改用
#    soundfile 解码）——省 24 MB。onnxruntime 与 av 看似未用，但它们是 faster-whisper 的声明依赖，必须保留。
